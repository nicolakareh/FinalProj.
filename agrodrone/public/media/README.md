# Media assets

Drop finished assets here with these exact names, then point `content/site.ts` at them.

| File | Used by | Intended shot |
| --- | --- | --- |
| `hero.mp4` (+ `hero-poster.jpg`) | Hero background | Spray drone crossing a crop field at golden hour, low angle, slow lateral tracking, 8 to 12 s seamless loop, no audio. Set `hero.video` and `hero.videoPoster` in `content/site.ts`. |
| `service-fertilizer.jpg` | Services tab: Fertilizer | Granular spread over young corn, drone low in frame, dawn light. |
| `service-protection.jpg` | Services tab: Crop protection | Fine spray over a mature canopy, side light showing the droplet curtain. |
| `service-seeding.jpg` | Services tab: Seeding | Seed broadcast into tall standing corn, top-down, late summer. |
| `service-mapping.jpg` | Services tab: Field mapping | Tablet held over a field showing the as-applied map, field behind it. |

Until a file exists, the site renders a labeled placeholder block in its place.
